4. AI / LLM runtime boundary
------------------------------------------------------------------------

The submitted prototype uses a deterministic local MockLlmAdapter at the
AI Scribe inference boundary (src/lib/ai/llm-adapter.ts). Its output is a
pure function of its input. No external LLM API is invoked by the
submitted application: no OpenAI, Anthropic / Claude, or other hosted
model service is called at runtime, and no model API key is required.

AI Scribe ingestion, PHI redaction, persistence, provenance, and audit
logging are real (src/app/api/patients/[id]/ai-scribe/route.ts); only the
summarization step is mocked. No external machine-learning model is
bundled or distributed with this project.


5. AI-assisted development process
------------------------------------------------------------------------

Development of this prototype used a structured, prompt-driven workflow
with an AI coding assistant (Claude), including feature implementation,
automated test creation, iterative debugging, documentation work, and
evidence-based review gates. The workflow used explicit STOP conditions
when evidence was insufficient or when repository state did not match
assumptions. Final code, tests, architecture claims, performance
evidence, and submission statements were checked against the final
repository state rather than inferred from planning documents.

Human direction remained part of the process throughout: scope
decisions, acceptance or rejection of proposed changes, manual browser
verification, and repository review were performed by the author. This
was not test-driven development — implementation was followed by targeted
automated regression, iterative debugging, and evidence review. Browser
and render behaviour was verified manually, not by an automated
end-to-end suite.

The three earliest bootstrap commits carry historical
"Co-Authored-By: Claude Sonnet 4.6" trailers; later commits do not. Git
history has not been rewritten.

This section describes the development process only. It does not change
the runtime boundary stated in section 4.


6. Demo data
------------------------------------------------------------------------

All demo clinics, users, and patient records are synthetic and were
created for this prototype (prisma/seed.ts). No real patient data and no
external clinical dataset were used.
